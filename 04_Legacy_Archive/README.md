# 🗄️ Legacy Optimizations Archive (2022–2024)

> [!WARNING]
> The scripts and registry files stored in this archive are historical community tweaks collected between 2022 and 2024 (Alchemy Tweaks, Ancel, RIP Tweaks, Melody Low Latency).
> 
> Many of these legacy scripts apply indiscriminate blanket registry modifications that can:
> 1. Disable Windows Defender or driver signature verification, triggering **Riot Vanguard Error VAN 9003 / VAN 1067** or Easy Anti-Cheat kicks.
> 2. Break Windows Update, Bluetooth, or Wi-Fi connectivity.
> 3. Cause DPC audio starvation by setting `audiodg.exe` to Idle priority.
>
> **Recommended Action:** Use the modernized, tested, and kernel-verified scripts in [`01_Esports_Stack/`](../01_Esports_Stack/) for tournament-legal, zero-stutter performance.

---

## Directory Contents

* **`Alchemy_Tweaks/`**: Historical DPC, timer serialization, and DWM render batch files.
* **`Ancel_Tweaks/`**: Early network configuration and fullscreen optimization scripts.
* **`BIOS_and_SCEWIN/`**: AMI BIOS NVRAM variable modification scripts and SCEWIN utilities.
* **`Melodys_Low_Latency_v3/`**: Standalone Visual Basic GUI latency utility.
* **`RIP_Tweaks/`**: Legacy registry tweak packs and emergency network/game restore scripts.
